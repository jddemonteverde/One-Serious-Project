# Repository guidance

## Project status

This repository is at the bootstrap stage. Application code, infrastructure,
deployment configuration, and automated checks will be added as the project develops.

## Working in this repository

- Read `README.md` and relevant documentation before making changes.
- Follow the requested scope and keep changes focused.
- Use the directory layout documented in `README.md`.
- Follow `.editorconfig` and any conventions established in the files you edit.
- Document new setup steps and development commands in `README.md`.
- Record significant architecture decisions in `docs/adr/`.
- Run checks relevant to the change when available, and report what was verified.
- Keep credentials, private keys, and local environment files out of version control.

Empty directories contain `.gitkeep` placeholders. Remove a placeholder when its
directory gains substantive tracked files.

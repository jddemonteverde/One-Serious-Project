# Repository guidance

Read and follow [AGENTS.md](AGENTS.md), the canonical cross-agent engineering
contract for this repository. For each task:

1. Identify the current OSP ticket and its acceptance criteria.
2. Inspect the existing repository before making changes.
3. Stay within ticket scope.
4. Run relevant validation and report any checks that could not be run.
5. Distinguish target architecture from implemented architecture.
6. Make significant architecture choices explicit to the project owner; do not
   make silent architecture changes.
7. Inspect the actual Git diff before suggesting commit messages.
